# SkillJury Market Watch

This file is the durable baseline for weekly ecosystem research so daily runs do not repeatedly rediscover unchanged market facts.

## Rules

- The weekly strategy task owns the broad external scan.
- Daily stewardship should search externally only for specific deltas relevant to the current product decision.
- Record only meaningful changes with evidence.
- Do not restate unchanged competitor facts every week.
- Separate reported facts from inference.

## Core areas

- AI-agent skills ecosystems and installation/discovery layers
- MCP-hosted skills and centrally managed skill delivery
- Agent-skill security, provenance, lifecycle and audit tooling
- Competing skill directories and review/trust products
- Developer communities and adoption patterns
- Search demand and SEO landscape
- Funding, launches, standards and platform changes
